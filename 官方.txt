四、推理脚本规范
科普：后台评测系统将以如下命令调用选手的推理脚本：

python predict.py <data_txt> <result_json>
data_txt：测试图片路径列表文件（每行一条路径，如 test/Image/frame_00000.jpg）
result_json：选手脚本必须将检测结果输出至该路径
predict.py 须满足以下要求：

从 sys.argv[1] 读取图片路径列表，从 sys.argv[2] 获取输出路径
推理完成后，将结果以 JSON 格式写入 sys.argv[2]
脚本正常退出，返回码为 0
五、输出文件格式
result.json 须严格遵循以下格式，缺少任意字段将导致评测失败：

{
  "result": [
    {
      "image_id":    "frame_00000",
      "type":        3,
      "x":           120.5,
      "y":           45.0,
      "width":       200.0,
      "height":      180.0,
      "segmentation": []
    }
  ]
}
字段	类型	要求
image_id	string	图片文件名，不含扩展名（如 "frame_00000"）
type	int	类别编号，1-indexed 整数（1=battery，2=board，3=fire）
x	float	检测框左上角横坐标（像素）
y	float	检测框左上角纵坐标（像素）
width	float	检测框宽度（像素）
height	float	检测框高度（像素）
segmentation	list	本赛题无需分割，填空列表 [] 即可
若某张图片无检测目标，无需在 result 中为其添加条目
result 数组可为空（[]），表示对所有图片均无检测结果
