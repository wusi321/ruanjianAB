  ## 1. 怎么把 LabelMe JSON 转成和官方一样的 XML？                                                                                                                                       
                                                                                                                                                                                         
  两种方式：                                                                                                                                                                             
                                                                                                                                                                                         
  ### 方式 A：用我刚写的脚本（推荐）                                                                                                                                                     
                                                                                                                                                                                         
  运行方式：                                                                                                                                                                             
                                                                                                                                                                                         
  # 批量转换                                                                                                                                                                             
  python json2voc.py "D:\你的LabelMe标注文件夹" "D:\ruanjiain\bbbbbb\annotations"                                                                                                        
                                                                                                                                                                                         
  # 单个转换                                                                                                                                                                             
  python json2voc.py "D:\你的标注\sample_001.json"                                                                                                                                       
                                                                                                                                                                                         
  转换逻辑：                                                                                                                                                                             
                                                                                                                                                                                         
  - LabelMe 矩形标注（两个点 [[x1,y1],[x2,y2]]）→ Pascal VOC 的 <bndbox>                                                                                                                 
  - 自动填入 Unspecified / truncated=0 / difficult=0，和官方格式一致                                                                                                                     
                                                                                                                                                                                         
  ### 方式 B：LabelMe 自带的转换工具                                                                                                                                                     
                                                                                                                                                                                         
  LabelMe 官方也提供了一个脚本，用 pip 安装后就有：                                                                                                                                      
                                                                                                                                                                                         
  # 安装                                                                                                                                                                                 
  pip install labelme                                                                                                                                                                    
                                                                                                                                                                                         
  # 用 labelme2voc.py 转换                                                                                                                                                               
  python -m labelme labelme2voc <输入目录> <输出目录> --labels labels.txt                                                                                                                
                                                                                                                                                                                         
  但据我所见，它输出的 VOC 格式有些差异（会把图片也拷贝过去），不如我写的脚本简洁。

  ## 2. 训练模型，什么格式都行吗？                                                                                                                                                       
                                                                                                                                                                                         
  结论：格式不重要，但建议统一成 VOC XML。                                                                                                                                               
                                                                                                                                                                                         
   格式                          谁用                                   优缺点                                                                                                           
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━                                                                              
   Pascal VOC XML（官方格式）    MMDetection、Detectron2、自定义训练    优点：和官方数据一致，方便对比验证                                                                               
  ────────────────────────────  ─────────────────────────────────────  ────────────────────────────────────                                                                              
   COCO JSON                     Detectron2、MMDetection、YOLOv5/v8     优点：一个文件管理所有标注，加载快                                                                               
  ────────────────────────────  ─────────────────────────────────────  ────────────────────────────────────                                                                              
   LabelMe JSON                  只存标注，不用于直接训练               缺点：大多数框架不支持原生解析

  关键问题不是"格式能不能训练"，而是 你的训练框架吃什么格式。                                                                                                                            
                                                                                                                                                                                         
  ### 如果你还没决定用什么框架：                                                                                                                                                         
                                                                                                                                                                                         
  建议做法：用 LabelMe 标注 → 转成 VOC XML（和官方一样）→ 将来不管用 MMDetection 还是 Detectron2 都有原生支持。这也是我把脚本写成转 VOC XML 的原因。
